# История изменений

## 1.0.0
- Foreground-сервис с MTProto→WebSocket прокси (ядро Flowseal/tg-ws-proxy 1.11.2).
- Интерфейс со всеми параметрами ядра, проверка ввода, автосохранение; русский/английский, светлая/тёмная тема.
- Настройка прокси в Telegram по `tg://proxy`; ярлык «Telegram + прокси» (работает при полностью закрытом приложении).
- Режим экономии батареи по активности окна Telegram, отладочные уведомления.
- Обновление ядра с GitHub с проверками и автоматическим откатом.
- Вкладка ADB: гайд и проверка отключения фонового «убийцы» процессов.
- Плитка быстрых настроек с синхронизацией состояния.
- Логи прокси и приложения, экраны разрешений и оптимизации батареи.

# История изменений

## 1.0.1
- Ядро Flowseal/tg-ws-proxy обновлено до 1.11.4.
- Настройка «Выключить TLS для CF-прокси и CF-worker» (`--no-secure`) переименована в соответствии с Windows-версией; добавлен «Макс. размер лога, МБ» (`--log-max-mb`).
- Исправлен чёрный квадрат в логе прокси; на экране только хвост лога, добавлен просмотр всего лога с постраничной навигацией.
- Встроенное обновление приложения со страницы релизов GitHub (скачивание APK и установка).
- CI: восстановление постоянного ключа подписи из секрета `DEBUG_KEYSTORE_B64`.

## 1.0.0
- Foreground-сервис с MTProto→WebSocket прокси (ядро Flowseal/tg-ws-proxy 1.11.4).
- Интерфейс со всеми параметрами ядра, проверка ввода, автосохранение; русский/английский, светлая/тёмная тема.
- Настройка прокси в Telegram по `tg://proxy`; ярлык «Telegram + прокси» (работает при полностью закрытом приложении).
- Режим экономии батареи по активности окна Telegram, отладочные уведомления.
- Обновление ядра с GitHub с проверками и автоматическим откатом.
- Вкладка ADB: гайд и проверка отключения фонового «убийцы» процессов.
- Плитка быстрых настроек с синхронизацией состояния.
- Логи прокси и приложения, экраны разрешений и оптимизации батареи.
